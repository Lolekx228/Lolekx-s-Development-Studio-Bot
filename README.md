## Что изменено 14 октября 2026

- Убраны оригинальные логотипы, рекламные изображения, приветственный текст и название из рабочего интерфейса. Используется LDS Studio.
- Сохранены классические панели, настройки, Backups, Clear All, Share Message, Content, Profile, Thread, Flags, Files, поля embeds, перемещение/дублирование/удаление, JSON Data Editor, Add Message и Message Link.
- Сохранён оригинальный режим Webhook: отправка, вложения, профиль, форумные ветки, загрузка и редактирование сообщения по ссылке. Для этих действий нужны действительный webhook и соответствующие права Discord.
- Добавлен режим LDS Bot: API по HTTPS, вход через Discord, выбор сервера/канала или ID существующей ветки, отправка текста и embeds, нескольких сообщений по порядку. Сессия сохраняется в sessionStorage текущей вкладки и проверяется API после перезагрузки. Повтор незавершённой отправки сохраняет идентификаторы и пропускает подтверждённые сообщения. @everyone и @here в режиме бота отключены.
- Файлы, замена имени/аватара, создание форумной ветки, тихая отправка и редактирование доступны через Webhook; текущий API LDS Bot отправляет текст и embeds. Если такая функция задана, отправка через бота выдаёт понятную ошибку вместо потери данных.
- Share Message создаёт обычную ссылку с сообщением без внешнего сервиса сокращения ссылок. Она не содержит пароль API или токен бота. Сообщение доступно каждому, у кого есть ссылка.
- Страница экспортируется статически для GitHub Pages, включая viewer. На телефоне редактор и предпросмотр переключаются вкладками. Прежний редактор Components V2 сохранён по кнопке в шапке.
- Next.js обновлён до 12.3.7 для совместимости статической сборки с Node.js. Добавлена совместимость закреплённого Yarn 2 с Node 22/24.

## Загрузка в твой GitHub

1. Распакуй архив. Загрузите **содержимое** в репозиторий Lolekx228/Lolekx-s-Development-Studio-Bot, заменяя старые файлы docs. Файлы сайта должны быть в docs/index.html, а исходники — в source/. Папку с названием архива поверх репозитория создавать не нужно.
2. Сохрани существующие файлы бота и секреты вне публичного репозитория. Архив сайта не содержит .env, паролей и токенов.
3. Settings → Pages: оставь GitHub Actions либо main /docs (в зависимости от уже выбранного способа). Готовая папка docs не требует сборки на GitHub. Если workflow работает через Actions, скрытая папка .github тоже должна попасть в репозиторий.
4. Дождись публикации и открой https://lolekx228.github.io/Lolekx-s-Development-Studio-Bot/ с Ctrl+F5.
5. Режим LDS Bot уже содержит https://lolekx-api.wispbyte.app. Обнови bot-api на Wispbyte и настрой OAuth по НАСТРОЙКА-DISCORD.txt. Нажми «Войти через Discord» и выбери канал.

## Изменение исходников и повторная сборка

Node.js 22 или 24. Из каталога source:

```sh
node --require ./scripts/node-compat.cjs .yarn/releases/yarn-2.4.0.cjs install
node scripts/build-pages.cjs
node node_modules/typescript/bin/tsc --noEmit
node --test modules/editor/bot/client.test.cjs
```

Сборка пишет готовые файлы в ../docs. Сборка копирует отдельный редактор Components V2 из components-source в docs/components. По умолчанию базовый путь — /Lolekx-s-Development-Studio-Bot. Для другого репозитория задай переменную LDS_BASE_PATH перед сборкой (например, /my-editor). Пароль и DISCORD_TOKEN в код сайта не добавляй.

Проверки API-клиента выполняются с подменёнными ответами и не отправляют сообщения в Discord. Инструкции хостинга бота: bot-api/editor.env.example; файл запуска на Wispbyte — bot-api/start-with-editor.cjs. На хостинге сохраняй действующие .env и data.

## Обновление 15 октября 2026: Discord OAuth

Добавлен вход через Discord (authorization code, scope identify). Client Secret и обмен кода находятся только на Wispbyte. Доступ проверяется по OWNER_USER_ID и явному списку EDITOR_ALLOWED_USER_IDS; старый пароль отключён в режиме discord. Одноразовый код возврата привязан к браузеру отдельным подтверждением и не является bearer-токеном. Сессии API не сохраняются в URL и localStorage. В sessionStorage сохраняется ограниченная четырьмя часами сессия API, а незавершённый вход и URL черновика хранятся временно. Discord access/refresh tokens, Client Secret и токен бота в браузер не передаются. Реальный вход заработает после настройки Redirects и Client Secret, см. НАСТРОЙКА-DISCORD.txt.

## Исправление импорта и аккаунта 15 октября 2026

Backups → Import поддерживает экспорты Discohook 1–8, а версии 7/8 сохраняются без удаления данных сообщений. Можно также раскрыть «Вставить JSON бекапов» и вставить содержимое файла. Ошибки формата показываются в окне. Повторяющиеся названия получают суффиксы, старые бекапы не заменяются. Экспорт использует version 8.

Сообщения с компонентами открываются через Load в редакторе Components V2 / Embeds, чтобы сохранить и V2-блоки, и обычные ряды кнопок. В этом редакторе Import принимает полный файл бекапов и предлагает выбрать бекап и сообщение. JSON с метаданными вложений сохраняется, но сами файлы из blob-ссылок восстановить нельзя — нужны новые файлы или постоянные HTTPS-ссылки. Бекапы пользователя не включены в архив сайта.

Вход в аккаунт перенесён вправо в шапку. Имя пользователя и кнопка выхода показываются после подтверждения API. Перезагрузка страницы и переход между редакторами в той же вкладке сохраняют вход до истечения сессии (4 часа), выхода или перезапуска API бота. Закрытие вкладки завершает её сессию браузера. На временной сетевой ошибке сохранённая сессия не удаляется; недействительная/отозванная сессия очищается. После обновления со старой версии нужно войти один раз. Бота/API для этого исправления менять не требуется.
