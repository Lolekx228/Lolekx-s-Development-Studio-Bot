Отправить через бота

Войдите для отправки сообщений

Вход в аккаунт — справа вверху.

Discord подтвердит аккаунт владельца. Секреты приложения хранятся на хостинге бота.

Указать ID канала или ветки

Включите режим разработчика в Discord → правый клик по каналу → «Копировать ID». Канал должен принадлежать подключённому серверу.

Уведомления отключены по умолчанию. @everyone и @here всегда отключены.

Нужен только код? Используйте «Копировать JSON» и /say text.

Из редактора — в Discord

Для отправки с сайта подключитесь к API бота и выберите канал в панели справа и нажмите «Отправить в Discord». Сообщение придёт от подключённого бота.

1. Соберите сообщение и устраните ошибки проверки.

2. Нажмите «Копировать JSON».

3. В нужном канале вызовите /say и вставьте JSON в text.

4. Выберите pings: false, если не нужны уведомления пользователям и ролям.

Доступ к /say определяется настройками вашего бота. Embeds отправляются через сайт; текущая /say их игнорирует. Вложения пока не поддерживаются. Кнопки с custom_id требуют отдельного обработчика в боте. Для отправки подключитесь к API на хостинге бота через вход Discord. Токен бота хранится только на хостинге.
