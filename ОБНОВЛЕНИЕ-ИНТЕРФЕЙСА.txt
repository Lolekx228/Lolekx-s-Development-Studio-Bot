Обновление интерфейса — 18 октября 2026

Причина смены дизайна: бекапы с Components V2 и рядами кнопок открывались в отдельном редакторе со старой вёрсткой.
Теперь этот редактор использует классическую двухколоночную компоновку: панель сверху, редактор слева, предпросмотр справа, серые панели и синие кнопки, сворачиваемые блоки. На телефоне доступны вкладки Editor / Preview. Вход через Discord расположен справа вверху.
Backups, Clear All, Share Message, JSON, импорт и экспорт доступны в том же оформлении. Библиотека бекапов общая с основным редактором; сообщение и компоненты при переходе сохраняются. При первом посещении непосредственно /components/ без созданной основной базы бекапы сохраняются локально в отдельном хранилище и доступны через Export All.

Как обновить:
1. Загрузите содержимое архива в корень репозитория Lolekx228/Lolekx-s-Development-Studio-Bot с заменой файлов. Готовый сайт находится в docs/, исходники классического редактора в source/, исходники редактора компонентов в components-source/.
2. Дождитесь зелёного результата GitHub Actions / Pages.
3. Откройте сайт и нажмите Ctrl+F5.
Бота и API на Wispbyte для этого обновления менять не нужно. .env и data бота сохраните.

Проверено: загрузка V2 из основной библиотеки, сохранение и повторное открытие бекапа, сворачивание блоков, ссылка на сообщение, JSON и мобильные вкладки. 12 тестов импорта и сессий пройдены, все 8 сообщений из примера сохраняются без удаления полей. Отправка реальных сообщений при проверке не выполнялась.
