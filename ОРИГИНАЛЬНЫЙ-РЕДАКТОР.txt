Оригинальный редактор embeds — 18 октября 2026

Используется исходный классический редактор Discohook: Content, Profile, Thread, Flags, Files, Clipboard, Clear; сворачиваемые Embed с перемещением, дублированием и удалением; внутри Author, Body, Fields, Images, Footer; Add Embed, Message Link → Load, JSON Data Editor и Add Message. Компоненты EmbedEditor, EmbedAuthorEditor, EmbedBodyEditor, EmbedFieldEditor, EmbedImagesEditor, EmbedFooterEditor взяты из исходного проекта и не заменены упрощёнными формами.

Исправление: бекапы с embeds и обычными рядами кнопок раньше отправлялись в отдельный упрощённый редактор. Теперь они открываются в оригинальном редакторе. Ряды кнопок сохраняются в данных сообщения и отображаются в предпросмотре; их JSON можно изменять через JSON Data Editor. Кнопка Embeds в редакторе Components V2 также открывает оригинальную форму.

Components V2 — другой формат сообщений Discord, поэтому для него остаётся редактор блоков. Это не переключает обычные embeds на упрощённые поля. При открытии обычного сообщения из смешанного бекапа его перезапись сохраняет остальные сообщения в бекапе.

Webhook и LDS Bot, файлы, вход через Discord и перезапись бекапов сохранены. Для этого исправления достаточно обновить сайт: Commit → Push, дождаться Pages, Ctrl+F5. Дополнительно обновлять API на Wispbyte для этого исправления не нужно; для функций бота по-прежнему требуется API из предыдущего обновления.
